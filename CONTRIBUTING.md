# Contributing

Thanks for helping improve `uping`.

## Before you start

- Open an issue for larger changes before starting work.
- Keep pull requests focused on a single change.
- Follow the existing code style and keep changes small and mechanical where possible.

## Development

```bash
make
```

Use the existing build output and examples in `README.md` to verify behaviour.

## Pull requests

- Describe the user-visible change.
- Mention any platform-specific behaviour.
- Include reproduction steps for bug fixes.
- Update documentation when behaviour or usage changes.
